Binghamton Connect 首页 UI 设计方案
（基于留学生核心需求，贴合 Binghamton 官方视觉体系，兼顾美观与实用性）
一、整体视觉规范
主色调：Binghamton 官方绿色（色值 #006633，用于按钮、标题、导航高亮）
辅助色：黑色（文字主体，色值 #000000）、浅灰色（背景 / 卡片，色值 #f5f5f5）、白色（文字背景蒙版，色值 #ffffff）
字体：全局使用无衬线字体（如 Arial/思源黑体），标题加粗，正文常规，确保中英文显示协调
响应式适配：支持电脑端（优先）、平板端、手机端，核心模块在小屏设备自动换行 / 折叠
二、顶部导航栏（固定置顶，占屏高度 80px）
区域	设计细节	交互逻辑
左侧品牌区	- 校徽：Binghamton 大学官方校徽（尺寸 60px×60px，左对齐，边缘距左侧 20px）
- 平台名：Binghamton Connect（字体大小 24px，加粗，与校徽水平居中对齐，间距 15px）	点击校徽 / 平台名，跳转至首页（当前页）
中部核心导航	导航项（横向排列，间距 30px，字体大小 16px）：
1. 首页
2. 重要通知
3. 行前 & 在校生活
4. 学业支持
5. 就业规划
6. 二手 & 拼车	- 未选中：黑色文字，hover 时变官方绿色
- 选中（当前页）：官方绿色文字 + 底部 3px 绿色下划线
右侧功能区	- 搜索框：占位提示 “搜索课评 / 租房 / 通知”（宽度 200px，圆角 20px，右侧带放大镜图标）
- 个人中心：用户头像图标（尺寸 40px×40px，边缘距右侧 20px）	- 搜索框：输入时显示历史搜索 / 热门推荐
- 个人中心：点击弹出下拉菜单（登录 / 注册 / 我的收藏）
移动端适配	隐藏中部导航，替换为 “汉堡菜单”（三横线图标，右侧对齐）	点击汉堡菜单，弹出侧边导航栏（包含所有核心导航项）
三、动态背景轮播（导航栏下方，占屏高度 500px，宽度 100%）
3.1 轮播基础设置
切换方式：自动轮播（间隔 5 秒）+ 手动控制（左右箭头 + 底部指示器）
过渡效果：淡入淡出（避免生硬滑动）
蒙版：全图叠加半透明黑色蒙版（透明度 0.3），确保文字清晰可读
3.2 轮播内容（3 张核心图，按顺序循环）
轮播图主题	图片内容描述	叠加文字设计
Glenn G. Bartle 图书馆	图书馆正面全景（突出标志性拱门与玻璃幕墙，光线明亮）	- 校训：“从广度中追求卓越”（英文：“Pursuing Excellence from the Breadth”）
- 字体：28px，白色，加粗，居中偏下
- 位置：距离图片底部 80px
卓越中心（Center of Excellence）	现代风格建筑局部（强调金属质感与几何线条，体现学术创新氛围）	同左（校训文字位置不变，确保视觉统一）
山腰日落景色	从校园山腰俯瞰的日落全景（橙红色天空 + 远处树林，体现自然美景与校园氛围）	同左
3.3 轮播控制元素
左右箭头：白色半透明圆形按钮（尺寸 40px×40px），分别位于轮播图左右两侧居中位置，hover 时变为官方绿色
底部指示器：3 个圆形小点（直径 10px），横向居中排列，间距 15px，位于轮播图底部 30px 处
未选中：白色半透明
选中：官方绿色实心
四、核心功能模块（轮播图下方，采用 “2+2” 卡片布局，总宽度 1200px，居中显示）
模块通用样式
卡片尺寸：单张卡片宽 580px，高 220px，间距 40px，圆角 10px
卡片背景：浅灰色（#f5f5f5），hover 时轻微上浮（阴影加深）
标题区：左侧官方绿色图标（尺寸 30px×30px）+ 标题文字（20px，黑色加粗），间距 10px
内容区：正文文字（14px，黑色，行高 1.5），位于标题下方 15px
按钮区：“查看更多” 按钮（官方绿色背景，白色文字，圆角 20px， padding 8px×20px），位于卡片右下角
